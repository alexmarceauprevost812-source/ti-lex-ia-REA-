# 🎁 La clé de Michelle

**[⬇️ Télécharger Cle-USB-Michelle.zip](https://github.com/alexmarceauprevost812-source/ti-lex-ia-REA-/raw/cle-maman/telecharger/Cle-USB-Michelle.zip)**

Un mini-ordinateur sur clé USB-C, avec une assistante IA québécoise qui fonctionne **sans internet** une fois installée. Rien ne sort de l'ordinateur.

## Pour l'installer
1. Télécharge **Cle-USB-Michelle.zip** (le lien ci-dessus).
2. Branche la clé USB-C (formatée en **exFAT**) et ouvre-la dans l'Explorateur de fichiers.
3. Clic droit sur le ZIP › **Extraire tout…** › choisis la clé.
4. Sur la clé, double-clique sur **▶️ START**.
5. La première fois, l'appli **🧠 Modèles IA** s'ouvre : clique sur **Installer** sur le modèle ✅ Recommandé (il faut internet, de 10 à 40 minutes).

Pour mettre à jour plus tard : retélécharge le ZIP et extrais-le sur la clé en remplaçant les fichiers. Le dossier « Mes documents » n'est pas touché.
