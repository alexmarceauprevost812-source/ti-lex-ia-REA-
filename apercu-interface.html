Les 4 modes

1 · Chat

Conversation générale en français québécois. Rapide, sans outils.

2 · Codex

Assistant de code : il explique, corrige, propose des commandes exactes.

3 · REA

L'agent complet : cherche sur le web, décrit des images, lit/écrit des fichiers, lance des commandes.

4 · Heretic

Chat direct avec le modèle décensuré. Le seul vraiment sans filtre.

À quoi ressemble le Chat

Mode Chat
— Mode Chat — tape /menu pour revenir, /quit pour sortir —

toi ❯ salut, c'est quoi la capitale du Québec ?
ti-lex ❯ La capitale du Québec, c'est la ville de Québec elle-même.
        (À ne pas confondre avec Montréal, qui est la plus grande ville.)

toi ❯ /image ~/photos/facture.png combien ça coûte ?
Analyse de l'image avec le modèle de vision…
ti-lex ❯ La facture indique un total de 48,30 $.

Le Chat peut aussi « voir » une image grâce à /image — même si son propre modèle ne gère pas les images, le modèle de vision la décrit et le Chat répond dessus.

À quoi ressemble Codex

Mode Codex
— Mode Codex — assistant de code —

toi ❯ écris-moi une fonction Python qui lit un fichier .txt
codex ❯ Voici une fonction simple et sûre :

  def lire_texte(chemin):
      with open(chemin, encoding="utf-8") as f:
          return f.read()

  Appel : contenu = lire_texte("notes.txt")
  Je n'ai pas exécuté ce code ici — teste-le de ton côté.

Commandes (dans tous les modes)

CommandeCe que ça fait
/retenir …Mémorise un fait partagé entre les 4 modes (ex. /retenir je m'appelle Alex).
/image <chemin> [question]Décrit une image et l'ajoute à la conversation (Chat, Codex et REA).
/menuRevient au menu des 4 modes.
/quitFerme LexOS Pro.

La mémoire est commune aux 4 modes : ce que tu dis à Chat, Heretic le sait aussi. REA apprend en plus de ses erreurs d'outils pour ne pas les refaire.

Aperçu de l'interface — l'application réelle est le menu texte qui s'ouvre avec demarrer-lexos-usb.sh. Ceci est juste une maquette pour te montrer à quoi ça ressemble.
